# Violet Catalog

هذا المستودع مخصص لموقع كتالوج فيوليت.

## نشر الموقع

الموقع النهائي يكون داخل مجلد `site`.

بعد نسخ مجلد `site` من جهازك إلى هذا المستودع ودفع الملفات إلى فرع `main`، سيتم نشر الموقع عبر GitHub Pages.

الرابط المتوقع:
https://ameerr748.github.io/violet-catalog/

الزبون لا يحتاج حساب GitHub لفتح الرابط.

## المطلوب على جهاز فيوليت

مجلد الموقع يجب أن يحتوي على:
- index.html
- مجلد images
- أي ملفات assets يحتاجها الموقع

لا تغيّر أسماء الصور.
